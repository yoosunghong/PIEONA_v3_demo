# 아바타 카드와 마을 소셜 플레이

튜토리얼의 기존 밸런스 5문항·말투 2문항에 취미, 마을 분위기, 음식 취향 3문항을 추가했다. 새 취향의 공개 여부는 플레이어가 선택하며 기본값은 나만 보기다. 완료하면 첫 카드가 생성되고 마을의 **아바타 카드 확인** 또는 왼쪽 **아바타 카드**에서 다시 볼 수 있다.

카드에는 성향 분석, 세 가지 태그, 소개, 관계 레벨, 최근 기억을 표시한다. 자아별로 복구한 기존 경험치에 계정의 누적 탐험 경험치를 더해 100 XP마다 캐릭터 레벨이 오르며 3·5·7·10레벨에서 카드 버전과 장식이 진화한다. 새 대화는 경험치를 지급하지 않는다. 최초 획득, 해당 레벨 도달, 방문객의 카드 확인에는 뒷면 → 회전 → 빛 효과를 적용했다. 모션 줄이기 설정에서는 회전 애니메이션과 섬광을 생략한다. 보유한 자아는 무료로 전환하며 각 자아의 기억·튜토리얼·기존 경험치는 독립적이다.

마을의 방명록·팻말 버튼 아래에서 방문 중인 캐릭터의 레벨, 현재 XP, 다음 레벨까지의 진행률을 확인한다. 레벨 비공개 설정은 이 표시와 카드에도 동일하게 적용한다. 카드 UI는 파스텔 블루 배경과 푸른 글씨를 사용하며 카드 요약·태그·상세 본문·퀘스트의 작은 글씨를 확대했다.

## 새로운 자아와 퀘스트

첫 대화, 텃밭 가꾸기, 마을 꾸미기, 이웃 아바타 대화, 세 이웃 대화, 게임 세 판, 레벨 5의 일곱 퀘스트는 각각 새 자아 카드 한 장을 준다. 생성 버튼으로 보상 한 장을 사용한다. 서버 트랜잭션으로 보상을 소비해 동시 요청으로 중복 생성하지 못한다. 기존 자아는 그대로 유지하며 최대 여덟 개다. 달성한 보상은 대화나 배치를 삭제해도 유지한다.

## 친구와 맞이하기

허용된 기억이 새로 생기거나 수정되면 친구 프로필에 노란 느낌표를 표시한다. 비공개 기억의 변화는 방문자의 알림에 포함하지 않는다. 카드 확인 시 읽음 상태를 기록한다. 마을 입장 때 아바타가 허용된 기억과 공개된 활동에서 취향 힌트를 말풍선으로 제공한다. 주인이 마을에 없으면 대신 인사한다. 이 힌트는 입장한 방문자에게만 전달한다.

## 2인 게임

**미니게임 → 두근두근 타자 대결 / 도란도란 끝말잇기**에서 대결 방을 만든다. 친구는 같은 마을의 같은 게임 화면에서 참가한다. 세 번째 참가자, 다른 마을 참가, 다른 게임·생활 활동 중 참가는 거부한다.

- 타자: 3초 준비 후 60초. 같은 문장을 순서대로 입력한다. 서버가 문장, 순서, 입력 간격과 시각을 검사하며 정확한 문장만 점수로 인정한다. 붙여넣기·드롭은 입력 UI에서 막는다.
- 끝말잇기: 3초 준비 후 차례마다 15초. 공유된 마을 단어장에 있는 단어, 중복 여부, 첫 글자, 두음법칙을 서버가 검사한다. 단어장은 게임 화면에서 검색할 수 있다. 일반 사전 전체를 지원하는 방식은 아니다.
- 마을을 떠나거나 포기하면 종료한다. 완료 결과는 SQLite에 저장한다. 골드·경험치 보상은 실제 진행한 판에 하루 열 판까지 적용하며 같은 결과를 재지급하지 않는다. 진행 중인 게임 방은 메모리에 있으므로 서버 재시작 시 유지되지 않는다.

## 밸런스 투표

마을 주인은 **마을 투표**에서 질문, 두 선택지, 참가 골드(0G 가능), 최대 시간(1–1,440분), 최대 표 수(2–50)를 설정한다. 마을마다 한 개의 투표를 활성화할 수 있다. 활성 투표함은 노란 테두리와 빛나는 링, **투표가 있습니다** 말풍선으로 표시한다.

주인과 방문객 모두 **참석하고 아바타에게 맡기기**를 누른다. 서버 내부의 성향 판단이 기억과 활동의 관련성을 비교해 A/B를 고른다. 외부 AI로 내기·기억 데이터를 전송하지 않는다. 계정당 한 표이며 자아를 바꿔도 다시 투표할 수 없다. 투표한 뒤 아바타별 선택을 확인한다.

마감 시간 또는 최대 표 수 도달 시 서버가 자동 종료한다. 다수 선택 참가자들이 전체 내기 골드를 똑같이 나누며 나머지 1G 단위는 저장 순서로 배분한다. 동률 또는 수동 종료는 전액 환불한다. 투표·참가·차감·지급 결과를 SQLite에 저장하므로 재시작 후 지난 마감을 처리하고 재정산하지 않는다.

## 분석과 공개 범위

카드는 현재 자아의 확인된 기억, 공개 관심사, 실제 배치의 종류·좌표·회전, 작물 상태, 완료한 게임의 종류·횟수·점수를 사용한다. 소유자와 방문자의 분석 캐시를 분리하고 매번 허용된 근거의 지문을 확인한다. 공개 철회·차단·자아 변경 중 생성한 결과는 폐기한다. 레벨 숨김 설정도 카드에 적용한다.

기존 Gemini 텍스트 분석 경로는 허용된 기억 텍스트를 분석한다. 새 배치·게임 관찰 정보는 외부 모델에 보내지 않고 서버 내부에서 성향 설명과 태그를 보완한다. Gemini 미설정·연결 실패 시 관찰 기반 분석임을 화면에 표시한다. 투표 판단도 서버 내부 규칙 기반이다.

## 리소스와 검증

새 일러스트는 내장 imagegen으로 생성했다. 프로젝트 리소스: `public/images/avatar-cards/portraits.png` (4열 아틀라스). 카드 뒷면·하트·빛·진화 테두리는 CSS로 구현했다. [원본 생성 프롬프트](avatar-card-image-prompt.txt)를 함께 보관했으며, 한국어 요약은 다음과 같다.

> 1536×1024 가로 캔버스를 동일한 네 개의 세로 초상화로 구성한다. 포근한 마을 정원의 고품질 3D 치비 인형: 베이지 머리·호박색 눈·토끼 인형, 분홍 머리·머리 위 토끼·분홍 카메라, 남색 머리·고양이 헤드폰·검정 고양이 인형, 상아색 머리·고글·펭귄 인형. 큰 반짝이는 눈, 섬세한 머리카락, 따뜻한 보케와 파스텔 조명. 각 캐릭터는 자기 패널 안에 배치한다. 글자, UI, 테두리, 워터마크는 넣지 않는다.

`tests/avatar-cards.test.mjs`와 `tests/social-play.test.mjs`는 카드 생성·공개 철회·진화·퀘스트 소비, 친구 알림·맞이, 2인 게임 판정, 중복 참가, 투표 마감·환불·골드 보존과 재시작 후 정산을 검증한다. 기존 채팅 복원 테스트는 카드 보상을 받은 계정이라는 조건을 추가했다. 브라우저 검증은 운영 데이터와 분리한 메모리 DB를 사용한다. 디자인은 첨부 이미지의 구조와 분위기를 기준으로 구현했으며 정량적인 95% 유사도 측정은 수행하지 않았다.

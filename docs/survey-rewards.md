# 설문 참여 보상

설문 제출에 성공하면 `survey-dragon-v1` 보상을 계정당 한 번 지급한다. 아기용 탈것 한 종류와 마을 장식용 전용 둥지 한 개를 해제한다. 탈것은 캐릭터 꾸미기의 내 플레이어 → 탈것에서 선택하고 색상을 바꿀 수 있다. 마을에서 F 또는 탑승 버튼으로 타고 내리며 WASD / 조이스틱으로 비행한다. 둥지는 마을꾸미기의 장식 카테고리에서 배치·회전·보관할 수 있다.

## 지급과 보관

- `account_rewards`의 `(user_id, reward_id)` 기본 키로 중복 지급을 막는다. 설문 응답 저장·참여 완료 기록·보상 지급은 하나의 트랜잭션이다.
- 서버 시작 시 `survey_participation.completed=1`인 기존 계정에도 지급한다. 문항 버전이 달라도 지급하며, 이후 버전 변경이나 자아 슬롯 전환으로 보상을 잃거나 중복 수령하지 않는다.
- 지급 기록은 익명 설문 응답 ID·응답 내용·제출 시각을 보관하지 않는다.
- 미참여 계정의 아기용 탑승 및 둥지 배치는 서버에서 차단한다. 다른 외형 저장 API나 보관 상태로 우회할 수도 없다. 둥지는 배치·보관 상태를 합쳐 한 개만 저장할 수 있다.
- 팝업 안내 닫기는 브라우저의 계정별 localStorage에 저장한다. 설문 미루기와 별도로 동작하며, 완료 시 설문 버튼과 안내가 사라진다.

## 모델과 이미지

`src/dragonModels.mjs`가 실제 마을·꾸미기 미리보기에서 사용하는 Three.js 모델이다. 아기용은 Crystalwing 원본 FBX를 16본으로 리깅하며, 날개짓·꼬리 움직임·공중 대기와 탑승을 지원한다. 몸통은 서 있는 플레이어 머리 높이에서 비행한다. 둥지는 나뭇가지 아치, 담쟁이, 수정, 등불, 쿠션과 작은 물줄기로 구성한다.

`public/images/rewards/`의 여섯 PNG는 같은 모델을 렌더링한 이미지다. 설문 초대·설문 본문·상단 안내·지급 확인 화면에서 사용한다. 모델 변경 후 개발 서버가 실행된 상태에서 다음 명령으로 갱신할 수 있다(개발용 Playwright 및 Chrome/Chromium 필요).

```powershell
node scripts/render-survey-rewards.mjs http://127.0.0.1:5173/
```

Playwright나 Chrome 경로를 직접 지정할 때는 `PLAYWRIGHT_MODULE`, `CHROME_EXECUTABLE` 환경 변수를 사용한다. 클라이언트 빌드와 서버 재시작 후 변경 사항이 적용된다.

## 검증

`tests/survey-rewards.test.mjs`는 미참여 접근 차단, 잘못된 제출·미루기의 미지급, 동시 제출 중복 방지, 다섯 색상 저장, 방문자 표시, 둥지 한 개 제한, 재로그인 보존, 기존 완료자 지급과 DB 재시작을 검증한다.

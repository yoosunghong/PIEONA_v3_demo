## 해석 범위

이 테스트는 10개의 인증된 WebSocket 계정, 약 15Hz의 마을 이동 송신, 약 10Hz의 게임 입력, 서버 권위 배구 시뮬레이션·스냅샷, 경기 종료/결과 저장/재매칭을 실행했다. ACK 지연에는 네트워크 왕복과 서버 처리가 포함된다. 이동 이벤트는 throttle/volatile 전달이므로 송수신 수가 일치하지 않을 수 있다. CPU는 Node 프로세스의 CPU 시간이며 전체 VM CPU·steal time과 다르다.

서버 동기화에 대한 수 분짜리 측정이다. Gemini 동시 호출, 실제 브라우저 FPS·GPU, 모델/텍스처 동시 다운로드, 공용 HTTPS 프록시, 대규모 기존 DB, 다른 종류의 미니게임, 장시간 버스트 제한·메모리 증가를 검증하지 않았다. 기존 2GB 스왑을 유지한 환경이므로 스왑 없는 1GB 서버 결과로 일반화할 수 없다.

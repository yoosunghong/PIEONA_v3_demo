# 초록 숲 탐험

2026-10-25. 제공된 `ILLOVA_content.md`와 숲 탐험 참고 이미지를 바탕으로 추가한 웹 MVP.

## 실행

`npm run dev` 실행 후 http://127.0.0.1:5173/explore 에서 플레이한다. 기존 마을의 **숲으로 출발** 버튼 또는 로그인 화면의 **초록 숲 먼저 둘러보기**에서도 진입한다. 운영 빌드에서는 `/explore`를 사용한다.

로그인한 계정은 SQLite의 `exploration_progress`에 계정별 진행을 저장한다. 비로그인 체험은 `illova.exploration.demo.v1` 로컬 저장소에 별도로 저장하며 서버 재화와 합치지 않는다. 체험의 시작 재료는 참고 이미지의 12/8/5/14, 피로도 68이다. 실제 계정은 재료 0, 피로도 100, 레벨 1로 시작한다.

## 현재 플레이테스트 조정

- 벌목·채광 타격당 피로도 2, 버섯·들꽃 채집당 1, 공격당 1로 소모량을 낮췄다.
- 귀환하면 탐험 HUD와 숲 렌더러를 종료하고 `/?view=village`의 기존 마을 UI로 이동한다. 체험 모드는 `/?view=village&demo=1`에서 같은 마을 UI를 사용한다. 귀환과 재입장 시 HP/피로도 100을 보장한다.
- 마을의 **숲으로 출발** 버튼으로 새 탐험을 시작한다. 제작은 마을의 **숲 공방** 버튼에서 별도 패널로 연다. 탐험 화면에서는 마을 UI를 겹쳐 표시하지 않는다.
- 숲 출발 전에 서로 수락한 친구의 아바타를 1명 선택하거나 혼자 출발할 수 있다. 로그인하지 않은 체험은 혼자 탐험한다. 친구 아바타는 실제 아바타 외형으로 렌더링한다. 선택된 친구 정보가 없는 이전 저장 데이터는 혼자 탐험으로 복구한다.

## 플레이

- WASD/방향키 이동, 클릭 이동 및 목표 선택, E 근접 채집/공격. 입력창에서는 게임 단축키가 작동하지 않는다.
- 나무·광석은 3회 작업, 버섯·들꽃은 1회. 작업 쿨다운, 공유 피로도, 30초 자원 재생성, 45초 슬라임 재생성을 적용한다.
- 슬라임은 순찰·추적·주기적 공격을 한다. 체력 0이면 재료 90%를 보존하고 마을로 귀환한다.
- I 가방, Q 퀘스트, M 지도, P AI 친구, Enter 명령 입력, Esc 패널 닫기. 터치 방향키 및 상호작용 버튼도 제공한다.
- 친구는 나무/돌/버섯 채집, 공격, 따라오기, 복귀, 대기를 지원한다. 최신 명령이 이전 명령을 취소한다. 완료한 자원 다음에는 같은 종류의 다른 자원을 찾아 계속 작업하며, 모두 소진되면 재생을 기다린다. 클릭 명령 메뉴의 중단은 제자리 대기다. 피로도 부족 시 중단하며, 접근 불가 목표는 다른 목표로 교체한다. 격자 경로 탐색으로 물길과 자원을 피한다.
- 직접 완료한 첫 경험에 20 XP, 몬스터 첫 처치 15 XP, 첫 제작 30 XP. 반복 경험은 한국 시간 기준 하루 20 XP까지. 레벨은 1~5이고 대화 횟수는 경험치를 주지 않는다.
- 확률적 설계도 드롭은 레벨별 미보유 설계도 중에서 선택한다. 실패 15회 이후 다음 유효 완료에 확정 획득한다. 여섯 제작법을 제공한다.
- 귀환하면 HP/피로도를 회복하고 기존 마을 UI로 전환한다. 공방은 마을에서 별도로 연다. 해금·재료 확인 후 제작하며, 배치는 기존 `village.items` 형식과 배치 가능 공간을 사용한다. 실제 마을에서 소품을 이동·꾸밀 수 있다.
- 플레이어와 친구의 활동 주체를 구분하고 직접 채집 기록으로 귀환 대사를 만든다. 로그인한 계정의 귀환 기억은 비공개 미확인 초안으로 저장한다. 아바타의 정체를 직접 공개하지 않는다.

## 구현

- `shared/exploration.mjs`: 결정론적 규칙, 필드 노드, 제작법, 명령 해석.
- `server/exploration.mjs`: 인증, 트랜잭션, 요청 ID 중복 방지, 거리·속도·재료 검증, 계정별 저장.
- `src/explorationWorld.js`: 독립 Three.js 숲, 기존 FBX 캐릭터, 새싹 동료, 인스턴스 풀·꽃·덤불, 선택 윤곽선, 도구 휘두르기/파편, 물결·꽃잎·이동 애니메이션. 정사영 카메라와 SSAO를 사용하며, 분홍 나무는 생성한 투명 컷아웃과 3D 공간을 결합한다.
- `src/Exploration.jsx`, `src/exploration.css`: 반투명 HUD와 공방/퀘스트/지도/친구 패널, 접근성 및 반응형 조작.
- `public/images/exploration/`: ImageGen으로 생성한 12종 투명 아이콘과 참고 이미지에 맞춘 나무 컷아웃. `icons.png`가 원본이고 나머지는 UI용으로 분리한 자산이다.
- 마을 캐릭터·아바타 카드 레벨은 기존에 획득한 경험치와 누적 탐험 경험치를 합산해 100 XP마다 오른다. 숲 안의 1~5레벨은 설계도 해금용 진행도로 별도 유지한다.
- `restore-avatar-levels-v1` 마이그레이션은 저장된 `avatar_experience`를 자아별 `avatar_legacy_experience`로 한 번만 복구한다. 이후 대화나 서버 재시작으로 경험치를 다시 지급하지 않는다. 최초 자아 생성 시 슬롯이 비어 있던 복구 기록도 함께 이전한다. 운영 배포는 배포 파이프라인의 DB 스냅샷 이후 서버 시작 시 적용한다.

## 검증 및 제한

전체 회귀 테스트 321건 중 318건 통과, 기존 선택적 테스트 3건 스킵. 탐험 규칙/API 테스트에는 거리·속도·피로도 검증, 동시 요청과 재전송의 중복 지급 방지, 대리 작업 XP 분리, 설계도 천장, 제작과 실제 마을 배치, 기존 대화 XP 제외를 포함한다. 브라우저에서 AI 벌목, 직접 버섯 채집, 재료·피로도 변화, 귀환 회복 및 공방 진입을 확인했다.

친구 명령은 **한국어 키워드 기반 로컬 해석**이다. 새 탐험 채팅을 Google/Gemini로 전송하는 연동은 자동 승인 검토에서 외부 전송을 이유로 거절되어 구현하지 않았다. 현재 화면에서도 로컬 해석임을 표시한다.

참고 이미지를 바탕으로 색감·장면 구도·HUD를 재현했으나, **이미지 유사도 95%를 정량 측정하거나 달성을 보증하지 않는다**. 현재 리소스는 실시간 3D 재구성이며, 원본 이미지와 지형·식생·음영의 세부 차이가 남는다. 서버 권한 없이 브라우저에서 재화가 지급되지 않으며, 체험 데이터는 실제 계정에 이전하지 않는다.

귀환 UI 수정 검증: 관련 테스트 23건 통과, 브라우저에서 숲 → 기존 마을 UI → 별도 출발 버튼 → 숲 → 재귀환과 마을 공방을 확인했다. 마을 화면의 탐험 HUD 요소 수는 0이다. 전체 회귀 검사는 326건 중 322건 통과·3건 스킵·소셜 duel 참여 상태 갱신 테스트 1건 실패였다. 이 실패는 단독 재실행에서도 재현되었고, 이번 변경에는 서버·공유 규칙·해당 소셜 테스트 수정이 없다.

## 친구 동행 업데이트 (2026-10-28)

- 마을 출발 및 공방의 다시 출발은 `/explore?depart=1`에서 동행 선택 화면을 연다. 1명을 선택하면 내 캐릭터와 친구 아바타가 함께 존재한다. 친구 아바타 또는 머리 위 부탁하기 버튼을 누르면 마을 대화하기와 유사한 말풍선에서 벌목·채광·채집·따라오기·중단을 선택한다.
- 서버는 수락된 친구, 양방향 차단 여부, 방문 허용, 선택한 자아 슬롯을 확인한다. 이후 변경으로 동행 자격이 없어지면 다음 요청부터 작업을 멈춘다. 친구 본인의 조작이나 보관함은 변경하지 않고 탐험자의 진행에 작업 결과를 기록한다. 동료 작업은 플레이어 직접 경험 XP를 주지 않는다.
- `shared/companionScripts.mjs`는 기존 PSS의 `selectVariant`/`renderVariant`를 재사용한다. 선택한 친구 자아의 적용된 페르소나 버전과 말투·활동성·장난기·다정함으로 요청용 템플릿 대사를 선택하며, 세 변형을 순환한다. 기존 생성 대본에는 요청 이벤트가 없으므로 요청용 대사는 로컬 템플릿을 사용한다. 기존 마을 활동 PSS 생성·적용·표시 확인 API와 커버리지 집계는 별도로 유지한다. 탐험 중에는 외부 AI를 호출하지 않으며 친구의 원본 대화·기억·성향 수치를 응답에 포함하지 않는다.
- 대사 말풍선은 6.5초 표시하거나 닫을 수 있다. `dialogue`에 이벤트·변형·페르소나 버전을 기록하고 요청 ID 재전송 시 같은 결과를 반환한다.
- 검증: 관련 규칙/API/PSS 회귀 테스트 37건 통과. `node scripts/verify-exploration-companion.mjs`는 메모리 DB와 실제 Edge로 출발·선택·명령 변경·중단·모바일·귀환을 확인한다. 먼저 `npm run build`가 필요하다. 실행 중인 서버나 실제 계정 데이터는 사용하지 않는다.

## 캐릭터별 숲 요청 대사 (2026-10-28)

Avatar Update는 기존 마을 이벤트 7개와 숲 요청 7개(벌목·채광·채집·따라오기·복귀·대기·공격)에 각각 3개씩, 총 42개 대사를 생성한다. 숲 요청은 동행한 친구의 현재 자아에 적용된 버전에서 선택하며 요청 수락을 말하고 작업 완료를 미리 주장하지 않는다. 따라오기·복귀·공격을 서로 다른 이벤트로 구분한다. 선택과 요청 ID 재전송 처리는 기존 탐험 저장 트랜잭션을 따른다.

기존 마을 대사 21개만 저장된 버전도 조회·복구할 수 있으며, 해당 버전에 없는 숲 요청은 기존 성향 템플릿으로 응답한다. 새 생성은 전체 14개 이벤트가 있어야 검증을 통과한다. 마을 UI 전수 검증 스크립트는 마을 이벤트만 검증하는 범위를 명시하며, 숲 요청 21개 변형의 저장 대사 선택·순환·재전송은 `tests/exploration-server.test.mjs`와 `tests/companion-scripts.test.mjs`에서 별도로 검증한다.

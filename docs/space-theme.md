# 우주 테마와 플레이어의 별

모든 계정은 광장별, 낚시별, 농장별을 가진다. 기존 `village` 저장 데이터와 장식 배치는 광장별로 이어진다. 내부 저장 키와 계정 ID는 유지하며 표시 용어를 별로 바꿨다.

## 조작

- **내 별 보기** 버튼으로 전체 화면 별 지도를 연다. 휠 줌아웃·줌인은 화면 전환을 일으키지 않는다.
- 별 또는 별 이름을 선택한 뒤, 옆에 나타나는 **이동**을 누른다. 이동 버튼은 기존 대화하기 프롬프트 스타일을 사용한다.
- Esc는 선택을 해제하고, 한 번 더 누르거나 현재 별로 버튼을 누르면 현재 별로 돌아간다.
- 광장별에서는 바다와 낚시 시설을 표시하지 않는다. 낚시는 낚시별의 연못과 나무 데크에서 진행한다.
- 농장별은 기존 9개 텃밭, 씨앗 지급, 물주기, 수확, 인벤토리 및 요리 기능을 사용한다. 농장별의 돌아가기 버튼은 별 지도를 연다.
- 별을 옮기면 낚시와 생활 작업을 종료하고 서버의 현재 별 및 위치를 갱신한다. 화면에는 같은 별의 플레이어만 표시한다.

## 배경과 디오라마

`src/spaceWorld.js`의 공통 플랫폼을 광장, 낚시, 농장, 별 지도에서 재사용한다. 광장별·낚시별에서 지도를 열면 해당 별의 실제 배치와 캐릭터를 복제하여 표시한다. 농장별과 나머지 별은 콘텐츠에 맞는 축소 모형으로 표시한다. 작은 원경 디오라마는 우주의 배경 장식이다. 이동할 수 있는 보유 별은 이름이 표시된 3개다.

테마는 은하수(`milkyway`), 오로라(`cafe`), 황혼(`twilight`), 태양 노을(`sunset`)이다. 별빛 정원과 모닥불 테마는 제거했다. 이전 `default`·`campfire` 저장값은 은하수로 읽고 저장한다. 태양 노을은 구름 위로 밝은 태양이 떠오르는 사용자 첨부 배경을 사용한다.

별 꾸미기의 바닥 플랫폼 색상은 `village.platformColor`에 6자리 HEX로 저장한다. 테마를 바꿔도 선택한 바닥색은 유지되며, 광장별·낚시별·농장별과 별 지도에 동일한 바닥색을 적용한다. 저장 전 미리보기와 저장하지 않고 나가기를 지원한다.

별 지도 렌더러는 화면을 닫아도 유지한다. 진입 전에 리소스를 준비하고 카메라를 현재 별에서 전체 별자리로 이동한다. 별을 선택해 이동하면 카메라가 접근한 뒤 도착 화면의 첫 렌더링을 기다려 교차 전환한다. 호버와 키보드 포커스는 별의 흰색 외곽선과 빛으로 표시한다. 움직임 줄이기 설정에서는 짧은 전환만 적용한다.

| 리소스 | 제작 방식 | 적용 |

## 숲 기능 종료와 데이터 보존

숲 진입, 농장 바로가기, 공방 버튼을 우측 메뉴에서 제거했다. `/explore`도 일반 별 화면을 표시한다. 서버의 숲 HTTP API와 소켓 핸들러는 등록하지 않는다. 이전 숲 데이터와 자아 슬롯 성향 기록은 삭제하지 않으며, 신규 계정과 기존 계정의 슬롯 처리를 위해 호환 스키마를 유지한다.

기존 숲 서버 통합 테스트는 기능 종료 사유를 명시하여 건너뛴다. 해당 소스와 회귀 사례는 보존되어 있고, 활성 별 이동 동작은 `tests/stars.test.mjs`에서 검증한다.

## 검증

- `npm run build`
- `node --test tests/capture.test.mjs tests/scene-camera.test.mjs tests/scene-rendering.test.mjs tests/stars.test.mjs tests/life.test.mjs tests/garden.test.mjs`
- `node scripts/verify-stars.mjs`: 휠 전환 금지, 바닥 색상 편집·저장과 테마 독립성, 별 지도 렌더러 재사용, 호버·별 이동, 농장 씨앗 심기, 모바일의 세 별 선택, 일반 모션 카메라 중간 프레임, 네 테마 전환, 숲 진입 종료.

브라우저 검증은 인메모리 DB를 사용한다. 실제 사용자 데이터와 운영 서버는 변경하지 않는다. 결과 화면은 `artifacts/stars/`에 저장한다.

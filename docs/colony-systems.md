# 채광·NPC 교류·별 개척·경쟁

별 활동의 **개척 · 편지**에서 발견한 별, 핵과 철광석, NPC 방문, 경쟁 편지와 전투를 확인한다. 계정 단위로 저장하며 자아 슬롯 사이에 공유한다.

## 조작

- **별 꾸미기 → 채광 로봇**을 배치하고 저장하면 즉시 가동한다. 기존 꾸미기의 이동·회전·삭제·보관을 사용한다. 별에서 로봇을 클릭하면 카메라가 접근하고 반투명 패널에 총 가동 시간·배터리·누적 철광석을 표시한다. 작동 중 드릴이 회전하며 동작 줄이기 설정을 따른다.
- **은하 지도** 또는 **개척 · 편지 → NPC 찾아가기**로 NPC의 별을 방문한다. NPC를 클릭하거나 **대화하기 / 거래하기**를 누른다. 대화할 때 NPC별 위시리스트를 하나씩 발견한다. 보유 아이템과 수량을 선택해서 건네면 NPC가 보답을 선택하고 호감이 쌓인다.
- 미니게임을 정상 완료하면 계정마다 독립적으로 `min(100%, 20% + 참여자 수 × 10%)`를 판정한다. 혼자라면 30%다. 발견한 별은 한 번에 하나만 대기하며, 이미 대기 중이면 새 발견으로 덮어쓰지 않는다. **핵으로 내 별로 만들기** 또는 **발견한 별 보내기**를 선택한다. 소유한 별은 **내 별 보기**와 실제 은하 별 수에 반영된다.
- 새 별을 소유하면 40% 확률로 NPC가 양보를 요청하는 편지를 보낸다. 해당 NPC의 별에 방문해 양보하거나 설득한다. 양보하면 지불한 핵의 두 배를 받고 별 소유권을 NPC에게 넘긴다. 꾸미기 배치·시설 위치와 숨김 상태·테마·바닥색·작물과 물주기 기록·로봇의 배터리 및 가동·수집 이력도 함께 이전한다. 양도 직전까지 생산한 철광석은 플레이어 보관함에 남고, 이후 생산분은 NPC에게 귀속된다. 이 이전과 핵 보상은 하나의 트랜잭션으로 처리한다. 설득 성공 시 별을 유지한다. 실패하면 **별 방어하기**로 전투를 시작한다.
- 방어전은 20초, 항로 3개, 우주선 15대다. 항로의 포탑 버튼으로 도착하기 전에 격추한다. 12대 이상 격추하면 승리한다. 우주선은 출현 6초 후 도착하고 발사 간격은 최소 350ms다. 패배하면 해당 별만 점령되어 이동과 특성 보너스가 중단된다. 편지의 **탈환전 시작**으로 다시 도전한다. 화면 닫기·새로고침·연결 종료로 전투 시간이 초기화되지 않는다.

## 조정 가능한 기본값

| 항목 | 기본값 |
| --- | --- |
| 로봇 재고 | 10대, 별 꾸미기 공통 소품 재고 |
| 로봇 생산·배터리 | 기본 철광석 1개/분, 충전당 60분 |
| 충전 비용 | 철광석 5개 |
| 핵 지급 | 최초 3개, 정상 완료한 미니게임당 1개 |
| 별 등급 | C 50% / B 30% / A 15% / S 5% |
| 등급별 보너스·소유 비용 | C 10·핵 1개 / B 20·2개 / A 35·3개 / S 50·5개 |
| 대화 호감 | 분당 최대 +1, 최대 1000 |
| 거래 호감 | 위시리스트 아이템 개당 +5, 그 외 +1 |
| 거래 보답 | 위시리스트: 핵(한 거래 최대 5개), 그 외 철광석 |
| 설득 확률 | `min(95%, 20% + 호감도 × 0.75%p)` |

초록별은 농장 화면, 붉은별은 광장 화면, 푸른별은 낚시 화면으로 방문한다. 별마다 꾸미기 배치·시설 위치와 숨김 상태·테마·바닥 색상을 독립적으로 저장한다. 초록별마다 텃밭 작물과 물주기 기록도 분리한다. 낚시 자리 점유와 세션은 방문한 별에 귀속된다. 특성 보너스는 생산이 이루어지는 별에만 적용하며 다른 별로 전파하거나 중첩하지 않는다. 아이템 보관함·씨앗 수량과 아바타 외형은 계정 공용이다. 초록별의 성장 속도는 물주기 간격 `5분 / (1 + 보너스/100)`에 적용한다. 푸른별은 낚시 성공 후 희귀 이상 물고기 확률에 표시된 `%p`만큼 더한다. 기본 낚시 성공률 70%는 유지한다.

로봇은 배치한 별에서만 생산하며 다른 별에 복제되어 표시되거나 중복 생산하지 않는다. 별을 떠나거나 오프라인이어도 배치한 별에서 남은 배터리 범위로 생산한다. 해당 별이 점령되면 채광과 배터리 소모를 중단하고 탈환 후부터 재개한다. 중단 시간은 소급 생산하지 않는다. 점령·탈환은 소유자와 배치 데이터를 이전하거나 초기화하지 않는다. 탈환하면 점령 직전의 시설·작물·로봇 상태로 이용을 재개한다. 서버는 경과 시간을 정산하고 배터리·생산 체크포인트를 함께 저장한다. 이동·보관·재배치는 같은 로봇 ID의 가동 이력을 유지한다. 삭제된 로봇의 과거 이력은 남기지만 생산은 중단한다.

## 저장·검증

`star_worlds(owner_id,star_id)`에 별별 배치를 저장한다. 광장별은 기존 `users.village`를 유지하며, 기존 계정의 나머지 별은 첫 이관 시 기존 배치를 별도로 보존한다. 기존 공유 로봇은 광장별에만 귀속시켜 중복 생산을 방지한다. 새로 소유한 개척별은 빈 소품 배치와 독립적인 기본 시설로 시작한다. 기존 농장별 작물과 정산 이력은 그대로 보존한다.

`server/colony.mjs`의 `colony_*` 테이블에 발견, 특성, 정산 체크포인트, 호감·발견한 소원, 편지·결정, 전투를 저장한다. 기존 `owned_stars`와 `inventory_entries`를 소유권·수량의 기준으로 사용한다. 게임 완료 트리거가 참가자별 정산 대상을 기록하고 완료당 한 번 처리한다. 클라이언트는 발견 여부·가격·보상·성공 여부를 지정할 수 없다.

- `node --test tests/colony.test.mjs tests/inventory-studio.test.mjs tests/stars.test.mjs tests/garden.test.mjs tests/life.test.mjs`
- `node --test tests/star-transfer.test.mjs`: 양도 데이터·이력의 일괄 이전, 중복 보상 방지, 저장 실패 롤백, 재시작 후 보존, 실제 점령·탈환 검증.
- `node --test tests/star-worlds.test.mjs`: 배치·시설·보너스·로봇·작물·낚시 자리·점령·저장 복원의 별별 격리 검증.
- `node scripts/verify-star-worlds.mjs`: 같은 종류의 별 간 이동, 꾸미기 저장, 로봇 표시, 독립 텃밭과 새로고침을 브라우저에서 검증. 캡처는 `artifacts/star-worlds/`.
- `npm run build`
- `node scripts/verify-colony.mjs`: 임시 인메모리 DB와 브라우저에서 로봇 클릭·발견·소유·지도 이동·NPC 거래·설득·전투·모바일을 확인한다. 캡처는 `artifacts/colony/`에 생성한다.
- `node scripts/verify-stars.mjs`: 기존 별 이동·농장·모바일 회귀를 검증한다.

검증은 운영 DB를 사용하지 않는다.

# AI 아바타의 게임 행동 툴

## 현재 기능과 이번 확장

기존 아바타는 페르소나·기억 기반 대화, 낚시, 공동 낚시, 씨앗 심기·수확·요리, 보관함·획득 기록 조회, 허용 설정에 따른 자율·오프라인 생활을 지원한다. 기존 생활 명령의 구조화 JSON 실행에 더해, 소유자 대화에서는 Gemini의 네이티브 함수 호출로 아래 행동을 선택한다.

| 툴 | 인자 | 실제 동작 / 예시 |
| --- | --- | --- |
| `move_to` | `target`, 선택 `x`, `z` | PLAYER / STORAGE / GARDEN / KITCHEN / POSITION. “나한테 와”는 서버의 현재 플레이어 근처로 초속 2.4 단위 이동. 플레이어가 멀리 움직이면 도착 전에 목적지를 갱신한다. |
| `sit_down` | 선택 `seatId` | 가까운 빈 벤치를 예약하고 이동 후 실제 앉기 자세로 전환. “벤치에 앉아”. |
| `stand_up` | 없음 | 동반자의 진행 중인 작업을 중단하고 벤치에서 일어나기. “일어나”. |
| `take_from_storage` | `item`, 선택 `quantity` (1–99) | 보관함으로 이동 → 실제 재고 픽업 → 플레이어 근처로 운반. “보관함에서 정어리 2마리 꺼내와”. |
| `stop_activity` | 선택 `actor` | 이동·생활 작업 취소. “그만하자”는 모델을 기다리지 않고 실행한다. |

기존 낚시·조회·텃밭·요리·자율 설정도 각각 이름 있는 툴로 등록했다. 전체 정의와 서버 액션 매핑은 `server/avatarTools.mjs`에 있다. 새 행동 추가 시 이 등록부, `lifeActionSchema`, 서버 실행기, 검증을 함께 확장한다.

## 실행 흐름

1. 소유자 채팅 → Gemini에 함수 선언을 제공한다. 부정·인용·가정·잡담에는 호출하지 않도록 지시한다.
2. 모델의 `functionCall`을 허용 목록 및 인자 스키마로 검사한다. 알 수 없는 툴, 추가 필드, 한 턴의 복수 호출은 실행하지 않는다.
3. 서버는 소유권, 로그인·현재 자아, 요청 세대, 접속, 위치 범위, 빈 벤치, 재고를 검증한다. 현재 위치·마을 배치·재고를 모델에 추가 전송하지 않는다.
4. 기존 100ms 생활 틱에서 실제 위치를 진행하고 Socket.IO로 이동과 자세를 동기화한다. 클라이언트는 기존 걷기·앉기 애니메이션을 사용한다. 운반 중에는 아이템 이름과 수량을 표시한다.
5. 시작 응답과 완료 알림은 서버 결과로 작성한다. 모델이 완료했다고 주장한 문장은 행동 결과로 사용하지 않는다.

유효한 키를 사용하면 중단을 제외한 명령은 Gemini가 선택한다. 키가 없거나 무효면 대표 한국어 명령만 보수적인 로컬 규칙으로 처리한다. 테스트 모드에서는 대표 명령에 로컬 경로를 사용해 외부 호출을 피한다. 방문자는 소유자의 아바타 행동이나 보관함을 제어할 수 없다.

## 물건 가져오기와 현재 제한

이 게임의 인벤토리는 계정 공용 보관함이며 별도의 플레이어 가방이 없다. 픽업할 때 보관함 수량을 줄이고 `avatar_carry`에 운반 수량을 원자적으로 기록한다. 플레이어 근처 도착 후 확인한 물건을 공용 보관함에 되돌려 넣는다. 먹기·선물·소비나 새로운 획득 기록은 발생하지 않는다. 중단, 마지막 접속 종료, 자아 전환, 정상 종료 시에도 되돌려 넣고, 비정상 종료 후 시작 시 남은 운반 수량을 한 번만 복구한다.

이동은 기존 생활 작업과 같은 직선 이동이다. 가구를 피하는 경로 탐색, 지속 따라가기, 임의 복수 행동 계획, 실제 손가락/팔의 운반 자세, 플레이어 전용 가방·사용·선물은 후속 범위다. 독립 행동을 여러 개 요청하면 순서를 확인하도록 하며 한 턴 한 툴만 실행한다. 보관함 왕복은 하나의 서버 작업이다.

## 검증

`node --test --test-concurrency=1 tests/avatar-actions.test.mjs`는 모델 툴 응답 파싱, 일반 대화, 실제 채팅→이동, 이동하는 플레이어 도착, 벤치 예약과 해제, 재고 픽업·운반·반환, 재시도·중단·권한, 재고 변경, 복구와 트랜잭션 롤백을 검증한다. 기존 생활 회귀와 전체 `npm test`, `npm run build`도 실행한다.

합성 문장 5건으로 실제 설정된 Gemini의 이동·앉기·가져오기·일어나기 함수 선택과 일반 대화 JSON 응답을 확인했다. 실제 계정의 게임 상태는 이 모델 검증에 사용하지 않았다. 서버 코드가 바뀌므로 적용하려면 서버를 재시작하고 브라우저를 새로고침한다.

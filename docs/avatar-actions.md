# 아바타 대화와 마을 생활

대화 상대는 플레이어 캐릭터 외형을 가진 AI 아바타다. 마을 주인이 접속 중이면 실제 캐릭터를 표시하고, 부재 중이면 같은 외형의 대화용 캐릭터를 표시한다. 펫은 별도 동물 캐릭터이며 대화 상대가 아니다.

## 내 마을 도착 질문

`POST /api/me/questions/arrival`은 계정의 `arrival_question` 이벤트에서 이미 도착한 질문을 제외하고 24개 중 하나를 65% 확률로 고른다. 35%는 질문 없이 지나간다. 모두 소진되면 다시 사용하지 않는다. 기록은 서버 DB에 저장되므로 재방문·새로고침에도 유지된다.

질문은 먼저 캐릭터 위의 `! 질문이 도착했어요` 알림으로 표시된다. 누르면 대화 세션에 실제 assistant 메시지로 저장하고 채팅 입력창을 연다. 질문을 포함한 서버 대화 기록이 다음 AI 응답의 맥락으로 전달된다.

## 방문 마을의 대화

입장하면 방문 대화 화면 배치에 접힌 채팅창이 표시된다. 기존 대화 유도 팝업과 하단 이동 안내 바는 표시하지 않는다. 채팅창을 열거나 세션을 선택해도 마을과 주변 캐릭터 및 카메라를 유지한다. 내용 공유 동의는 새 대화 생성 전에 기존 절차로 받는다.

전송과 답변 시점에만 상대 아바타의 위치를 한 번 읽어 0.65초 동안 포커싱한다. 약 2.6초 뒤 이전 카메라로 돌아가고, 이동하는 주인을 계속 추적하지 않는다. 수동 카메라 조작은 자동 포커싱을 취소한다. 돌아가기 버튼 또는 Esc는 채팅을 접고 이동을 다시 허용한다. 전송 후 입력 포커스는 입력창으로 복원한다.

## 펫과 플레이어 행동

펫은 마을 안을 배회한다. 가까이에서 E로 쓰다듬고, R로 부르면 현재 플레이어 위치 쪽으로 다가온 뒤 다시 배회한다. 입력창에 타이핑하는 키는 펫 조작으로 처리하지 않는다. 서버는 계정·마을·쓰다듬기 거리와 중복 요청을 확인한다.

펫의 낚시·요리·텃밭 작업·운반·자율 및 오프라인 생활 실행 코드는 제거했다. 기존 운반 중 아이템은 서버 시작 시 보관함에 한 번만 복구한다. 기존 획득·추억 기록은 보존한다.

플레이어의 낚시(E), 텃밭 심기·수확, 요리 및 보관함 조회는 유지한다. 채팅의 생활 명령도 플레이어만 실행한다. 방문자에게는 다른 계정의 생활 행동을 허용하지 않는다. 보관함·요리대·텃밭·낚시터는 반투명 사각형과 흰색 이름표를 표시한다.

## 검증

`npm test`와 `npm run build`. 질문 선택·소진·계정별 이력·대화 맥락은 `tests/arrival-questions.test.mjs`, 펫의 배회·권한·거리·중복 요청은 `tests/pet-wander.test.mjs`, 플레이어 생활은 기존 낚시·텃밭·요리 통합 테스트로 검증한다.

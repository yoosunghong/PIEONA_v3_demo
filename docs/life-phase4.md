# Phase 4 — AI 자율 생활·오프라인 정산·관계 기억

## 사용 방법

마을의 **AI 생활** 버튼 또는 보관함의 **AI 생활** 탭에서 자율 생활과 허용할 작업을 설정한다. 기존 계정은 기본적으로 꺼져 있다. 자동 요리는 레시피를 명시적으로 선택해야 재료를 사용한다.

| 명령 | 동작 |
| --- | --- |
| 자율 활동 시작해줘 / 알아서 생활해줘 | 현재 허용 설정으로 자율 생활 시작 |
| 자동 낚시 시작해줘 | 접속 중 자동 낚시 허용 |
| 내가 없는 동안 텃밭 관리해줘 | 오프라인 수확·재파종 허용, 낚시·요리 자동화 해제 |
| 없는 동안 자동 낚시 시작해줘 | 오프라인 낚시도 허용 |
| 자동으로 허브 생선구이 만들어줘 | 해당 레시피 자동 요리 허용 |
| 자동 요리 하지 마 / 오프라인 활동 꺼줘 | 각각 요리 소비 허용 또는 오프라인 활동 해제 |
| 없는 동안 뭐 했어? | 실제 저장된 최근 정산 보고 조회 |
| 우리 함께한 추억 알려줘 | 현재 자아의 실제 관계 기록 조회 |
| 그만하자 / 자율 활동 꺼줘 | 아바타 활동과 자율·오프라인 모드 중단 |

기존 단일 명령 “허브 심어줘”, “텃밭 수확해줘”, “같이 낚시하자”는 그대로 동작한다. 일반 대화는 작업을 중단하지 않는다. 자아 전환 시 이전 자아의 정산을 먼저 처리하고, 자율 설정은 기본 비활성 상태로 초기화한다.

## 접속 중의 자율 활동

매번 LLM을 호출하지 않고 서버 규칙으로 판단한다. 소유자가 내 마을에 접속 중일 때만 실제 월드 캐릭터를 실행한다.

1. 수확 가능한 작물이 있으면 해당 밭으로 이동해 수확한다.
2. 재파종이 허용되어 있으면 빈 밭에 설정한 씨앗을 심는다.
3. 허용한 레시피의 재료가 충분하고 요리 간격 10분이 지났으면 조리대로 이동해 만든다.
4. 낚시가 허용되어 있으면 빈 자리를 예약하고 3회 판정한다.
5. 낚시 후에는 짧게 산책하고 쉰다. 낚시가 꺼져 있고 할 작업이 없어도 산책·휴식을 선택한다.

각 작업 사이에는 30초 쉬는 시간을 둔다. 플레이어가 가까이 오면 최대 5분 간격으로 인사한다. 명시적 명령은 진행 중인 자율 작업을 취소하고 우선 실행한다. 기존 작업은 완료할 때 재료를 차감하므로 중단 전 손실이 없다. 사용자 중단은 모드 자체를 꺼서 다음 틱에 재시작하지 않는다. 설정 변경은 이전에 대기 중이던 모델 명령의 세대도 무효화한다.

낚시와 텃밭·요리의 실제 작업·예약·인벤토리 처리는 Phase 1–3의 공통 로직을 사용한다. 자동 요리는 일반·고급 물고기만 사용한다. 희귀·특별 물고기는 기존 수동 요리에서 직접 선택할 때만 소비한다.

## 오프라인 규칙

기획서에 상한 수치가 없으므로 아래 초기 밸런스를 `shared/autonomy.mjs`에 명시했다.

| 항목 | 초기 한도 |
| --- | --- |
| 정산 기간 | 내 마을 마지막 연결 종료 후 최대 2시간 |
| 낚시 | 45초마다 판정, 최대 80회(성공 시 각 1마리) |
| 수확 | 최대 작물 18개 |
| 요리 | 최대 음식 6개 |
| 심기·수확·요리 | 작업당 가상 시간 10초 |

낚시 성공률·희귀도는 기존 온라인 낚시와 동일하다. 오프라인에서도 한 아바타가 순서대로 작업한다. 수확→재파종→허용 요리→낚시 우선순위로 시간을 진행하고, 성장 대기만 남으면 다음 성숙 시각으로 진행한다. 실제 3D 월드나 LLM을 계속 실행하지 않는다. 기존 작물을 수확한 뒤에는 같은 작물로 다시 심고, 처음부터 빈 밭에는 설정한 씨앗을 심는다. 접속 중 재파종은 설정 씨앗을 사용한다.

종료 시점의 허용 설정을 저장하므로 재접속 후 켠 설정을 과거 시간에 소급하지 않는다. 오프라인 도중 중단 요청이 들어오면 그 시점까지만 정산하고 이후 작업을 끈다. 다중 탭 중 마지막 내 마을 탭이 나갈 때만 부재 기간을 시작한다. 다른 마을 방문도 내 마을의 부재로 취급한다.

부재 기간당 한 번만 정산한다. 한 번 정산한 뒤 같은 부재 상태에서 새로고침하거나 시간을 더 보내도 다시 보상을 주지 않는다. 다음 내 마을 접속·이탈로 새 기간이 시작된다. 서버 재시작으로 온라인 상태가 끊겼다면 마지막 5초 간격 하트비트와 실제 낚시·생활 작업 정산 시각 중 더 늦은 시각부터 부재를 계산한다. 재시작 전 미완료 수동 작업은 재개하지 않는다.

## 저장과 원자성

- `life_autonomy`: 현재 자아, 허용 설정, 온라인 여부, 마지막 접속/하트비트, 마지막 상태, 부재 시작, 종료 당시 허용 계획, 대기·요리 간격.
- `life_offline_reports`: 부재 구간과 정산 UUID, 실제 획득·소비·심기 결과, 확인 여부. `(owner_id, started_at)` 고유 제약.
- `life_memory_events`: 자아별 의미 있는 사실과 참가자, 실제 아이템, 시각, 잊기 여부. 사건 키 고유 제약.

오프라인 정산은 `BEGIN IMMEDIATE` 하나 안에서 수행한다. 공통 작업 서비스는 중첩 SAVEPOINT를 사용한다. 작물 변경, 재료 소비, 보상·도감·활동 기록, 관계 기억, 보고서, 정산 기준 시각이 함께 커밋되며 하나라도 실패하면 전부 롤백된다. 실패한 요청은 같은 부재 기준으로 다시 시도한다. 보고 확인은 지급과 별개여서 확인 버튼으로 아이템이 추가되지 않는다.

낚시 지급은 온라인과 오프라인 모두 `awardLifeFish`를 사용한다. 오프라인 낚시는 기존 `life_sessions`/`acquisition_events`에 `COMPANION`, `offline_fishing` 출처로 남긴다. 텃밭·요리는 기존 `life_operations`/`inventory_changes`에 남겨 오늘·최근 획득 질의와 보관함이 같은 사실을 읽는다.

## 관계 기억과 대화

모든 행동을 기억으로 복사하지 않는다. 최초의 공동 낚시 기록, 실제 희귀·특별 물고기 최초 발견, 작물별 첫 수확, 레시피별 첫 요리만 선별한다. 과거 기록이 있는 일을 새 최초 발견·수확·요리로 꾸미지 않는다. 일반 대화에서 추출된 취향 기억과 수치가 정확해야 하는 게임 사실은 별도 테이블을 유지한다.

공동 낚시는 양쪽 세션의 실제 참여 시간이 겹쳤는지 확인한다. 혼자 했거나 오프라인에서 한 일을 함께한 경험으로 바꾸지 않는다. 현재 자아의 최근 관계 사실만 소유자 대화 컨텍스트에 제공하고, 방문자의 컨텍스트에는 제공하지 않는다. 기존 일반 기억의 공개 정책은 그대로 유지한다.

**우리의 추억** 탭에서 사건과 시각을 확인하거나 잊을 수 있다. 잊은 사건은 숨김 표시를 남겨 다시 생성되지 않게 하며 대화 컨텍스트와 이전 대화 재사용 키도 갱신한다. 원본 획득·소비 기록과 보관함은 변경하지 않는다. 자아 슬롯별 사건이 분리되어 다른 자아의 추억을 인용하지 않는다.

## 검증 및 적용

`tests/autonomy.test.mjs`는 실제 HTTP·Socket.IO 접속과 주입 가능한 서버 시간/추첨을 사용한다. 기본 비활성, 실제 자율 이동·작업·산책·휴식, 명시적 요청 우선, 다중 탭, 한도, 중복 정산, 전체 롤백, 재파종·요리 재료 보호, 부재 중 중단, 관계 기억의 사실성·비공개·잊기·자아 분리, SQLite 재시작을 검증한다. 기존 낚시·텃밭·요리와 전체 프로젝트 회귀 테스트도 실행한다.

서버 종료 직전 체크포인트 검증을 포함한 자율 생활 통합 테스트 14개를 통과했다. 이후 행동 로그 검증을 추가한 전체 회귀 247개와 Windows 실행기 수명 검증 3개를 각각 실행하여 모두 통과했다. `npm run build`도 통과했다. 실행기 변경과 다음 세션 작업은 [인수인계 문서](NEXT_SESSION.md)에 정리했다.

프런트엔드 프로덕션 빌드는 통과했다. 이 세션에서는 브라우저 보안 정책이 로컬 미리보기 접근을 차단하여 데스크톱·모바일 시각 검증을 진행하지 못했다. 정책을 우회하지 않았다.

서버 재시작 후 브라우저를 새로고침하면 적용된다. 기존 데이터에 테이블을 추가하는 마이그레이션이며, 운영 데이터 초기화는 필요하지 않다. 선물·판매·전시·식사 애니메이션·사용자별 취향 기반 활동 선택은 기획서의 후속 범위로 남긴다.

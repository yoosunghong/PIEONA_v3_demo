# 마을 생활

플레이어가 시설을 클릭하거나 생활 패널의 버튼을 눌러 직접 낚시·심기·수확·요리를 한다. AI 아바타는 대화와 페르소나 기억을 제공한다.

- 낚시: 해안의 빈 자리 가까이에서 E로 시작한다. 45초마다 서버에서 판정하고 획득물을 계정 보관함에 넣는다. 이동·점프·종료 버튼·마을 이탈로 중단한다.
- 농장: 마을의 농장 버튼으로 들어간다. 기존 텃밭의 작물과 ID는 유지하고, 별도 농장에 총 9개를 3×3으로 배치한다. 빈 텃밭을 누르면 보유 씨앗 선택 창이 열린다. 심기를 완료하면 씨앗 1개를 소비한다.
- 성장과 물주기: 심기를 완료한 시각부터 5분 뒤 첫 물주기가 가능하다. 매번 물주기를 완료한 뒤 5분을 기다려야 하며, 밀린 시간을 여러 번의 물주기로 대신할 수 없다. 새싹 → 줄기 → 열매의 3단계로 표시하고, 세 번째 물주기 완료 후 수확 가능 상태가 된다. 접속을 종료해도 기록은 유지되지만 시간만으로 성장하지 않는다.
- 수확: 물 아이콘이 작물 아이콘으로 바뀐다. 수확을 완료하면 작물 1개와 같은 종류의 씨앗 1개를 계정 공용 아이템 인벤토리에 넣고 텃밭을 비운다. 요청 ID와 심기 ID로 중복 수확과 오래된 요청을 차단한다.
- 씨앗: 숲 획득 기능은 후속 구현이다. 현재 농장 첫 입장 때 계정당 한 번만 허브·토마토·꽃·딸기·사과 씨앗을 각각 3개씩 지급한다.
- 요리: 기존 네 가지 레시피와 딸기 1개 + 사과 1개를 사용하는 과일 샐러드를 선택한다. 서버가 재료를 검증하고 완료 시 한 번만 소비한다. 희귀 물고기는 직접 지정해야 사용한다.
- 보관함과 도감: 계정 공용 수량, 획득 시각, 최초 발견을 표시한다.
- 작업 취소: 이동·중단·마지막 탭 이탈은 완료 전 작업을 취소한다. 재료는 완료할 때 차감한다.

## 코드

| 영역 | 파일 |
|---|---|
| 생활 상태·낚시·작업 이동 | server/life.mjs |
| 텃밭·레시피·원자적 재료 소비 | server/gardening.mjs |
| 직접 조작 요청 검증 | server/lifeActions.mjs |
| 낚시 지급 | server/lifeRewards.mjs |
| 농장 3D 화면 | src/farmWorld.js, src/farm.css |
| 시설 UI | src/GardenStudio.jsx, src/KitchenStudio.jsx, src/InventoryStudio.jsx |
| 펫 산책·쓰다듬기·부르기 | server/petRuntime.mjs |

기존 저장 데이터는 유지한다. 과거 운반 중이던 재고는 서버 시작 시 보관함으로 한 번만 반환하는 호환 처리를 남긴다.

검증: npm test 및 npm run build. 브라우저 재배·수확·모바일 검증은 node scripts/verify-farm.mjs로 실행하고 artifacts/farm에 화면을 저장한다. 생활 회귀 테스트는 tests/life.test.mjs, tests/garden.test.mjs, tests/life-actions.test.mjs에서 확인한다.

# 다음 개발 세션

현재 생활 콘텐츠 구조는 [마을 생활](village-life.md)을 따른다. AI 대화 API에는 행동 툴이나 작업 실행 경로가 없다. 플레이어가 시설과 버튼으로 생활 콘텐츠를 직접 조작한다.

## 확인할 사항

- 실제 휴대전화에서 터치·소프트 키보드·화면 회전·성능 확인.
- 기존 저장 배치에서 생활 시설의 겹침 확인. 기존 배치를 임의로 이동하지 않는다.
- 대화·기억·공개 범위와 마을 방문의 회귀 확인.
- 짧은 첫 플레이에서 재미와 호기심을 전달하는 체험 설계 검증.

## 데이터와 운영

기존 계정·보관함·획득 기록·설문 응답을 보존한다. 과거 운반 재고는 한 번만 반환한다. 키·대화 원문·설문 답변은 행동 로그에 출력하지 않는다.

운영 배포는 [CI/CD](cicd.md), 서버 구성은 [Oracle 배포](oracle-deployment.md), 성능 측정은 [부하 테스트](oracle-load-test.md)를 참고한다.
